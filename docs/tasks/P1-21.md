## Objectif

- Journaux JSON (`slog`) avec identifiant de requête ; aucun jeton, mot de passe ni montant.
- Métriques Prometheus sur un port interne : `http_requests_total`, `http_request_duration_seconds`, `stockeval_evaluation_duration_seconds`, `import_jobs_total{status}`.
- `/healthz` (processus vivant) et `/readyz` (base joignable, JWKS en cache).

## Hors portée

Tableaux de bord et alertes (phase 5).

## Livrables

- `backend/internal/platform/observability/`
- Tests

## Critères d'acceptation

- [ ] Les quatre métriques apparaissent après une requête et une évaluation
- [ ] `/readyz` répond 503 quand la base est arrêtée
- [ ] Un test vérifie qu'aucune ligne de journal ne contient l'en-tête `Authorization`

## Contraintes

Le port des métriques n'est pas routé par Traefik.
