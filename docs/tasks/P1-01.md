# P1-01 — Squelette du monodépôt

**Agent** : Plateforme  
**Dépend de** : aucune  
**Statut** : à faire

## Contexte à lire

- CLAUDE.md
- backend/CLAUDE.md
- web/CLAUDE.md
- docs/tasks/README.md

## Objectif

Créer l'ossature du dépôt pour que toutes les autres tâches aient un endroit où atterrir et une CI qui les juge.

- Arborescence complète (voir `CLAUDE.md` et `backend/CLAUDE.md`), avec un `README.md` d'une ligne par répertoire vide.
- `backend/go.mod` (Go 1.24, module `github.com/<propriétaire>/finance-privee/backend`) avec un `cmd/server/main.go` minimal qui démarre et s'arrête proprement.
- `Makefile` avec toutes les cibles listées dans `CLAUDE.md`. Une cible dont l'outil n'existe pas encore affiche « non configurée (P1-xx) » et réussit, sauf `ci`, qui exécute réellement ce qui existe.
- `.golangci.yml` (govet, staticcheck, errcheck, gosec, revive, gofumpt).
- `.github/workflows/ci.yml` : `make ci` sur chaque PR et sur la branche principale ; gitleaks ; govulncheck.
- `.editorconfig`, `.gitignore` (binaires, `node_modules`, `.env*`, fichiers déchiffrés).

## Hors portée

Angular (P1-14), Dockerfile et Compose (P1-19), contrat (P1-03).

## Livrables

- Arborescence du dépôt
- `Makefile`
- `backend/go.mod`, `backend/cmd/server/main.go`
- `.golangci.yml`
- `.github/workflows/ci.yml`
- `.editorconfig`, `.gitignore`

## Critères d'acceptation

- [ ] `make ci` réussit en local
- [ ] Le workflow de CI est vert sur la branche principale
- [ ] Un secret factice ajouté dans une branche de test fait échouer gitleaks (preuve dans la PR, branche supprimée ensuite)
- [ ] `go build ./...` réussit dans `backend/`

## Contraintes

Actions GitHub épinglées par SHA de commit, pas par étiquette.

## Si c'est ambigu

Applique `docs/decisions.md`. Sinon, prends l'option la plus simple et réversible, ajoute une ligne Dxx dans la même PR et signale-la en tête de la description. Si cette option change un contrat, un schéma ou un résultat de règle, arrête-toi et signale-le.
