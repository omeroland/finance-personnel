## Objectif

Reproduire exactement la feuille, horizon de 20 ans seulement, pour comparer les deux modes côte à côte.

Comportements à reproduire (section `compat` de `rules.yaml`) :
- Moyenne : (somme − min − max) / 18, même avec moins de 20 années.
- Hausses du BPA : somme sur les transitions 2 à 19 (la première est ignorée) ; seuil 8.
- Une cellule vide entre deux valeurs vaut 0 ; une valeur précédente nulle donne l'erreur `ErrSheetDivZero`.
- Seuils sans borne basse (7, 8, 11a, 11c) ; règle 9 `>= 0` ; donnée absente = réussite, avec avertissement.
- Ratios importés de la feuille (P/E, ratio de distribution, dette / capitaux propres, P/B) utilisés tels quels ; règle 10 = le oui/non saisi (casse ignorée).
- Aucun seuil assoupli en compat.
