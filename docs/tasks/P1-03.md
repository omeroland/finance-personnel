## Objectif

Écrire `api/openapi.yaml` (OpenAPI 3.1) pour le module 1 et brancher toute la chaîne de génération.

Routes, toutes sous `/api/v1` :

| Méthode | Chemin | Rôle |
| --- | --- | --- |
| GET | `/stocks?mode=&horizon=` | Liste de suivi avec scores, sous-scores, verdict |
| POST | `/stocks` | Ajouter une action (symbole canonique `BOURSE:SYMBOLE`) |
| GET | `/stocks/{symbol}` | Fiche : séries, instantané, qualitatif, sources, conflits |
| PATCH | `/stocks/{symbol}` | Métadonnées et instantané |
| PUT | `/stocks/{symbol}/facts` | Remplacer des valeurs annuelles |
| PUT | `/stocks/{symbol}/qualitative` | Règles 1 à 4, rachat manuel |
| DELETE | `/stocks/{symbol}` | Retirer de la liste (l'archive reste) |
| GET | `/stocks/{symbol}/evaluation?mode=` | Évaluation calculée à la volée |
| POST | `/stocks/{symbol}/evaluations` | Calculer et archiver |
| GET | `/stocks/{symbol}/evaluations` | Historique archivé |
| POST | `/stocks/{symbol}/refresh` | Fournisseur de données : répond 501 jusqu'à la phase 3 (D32) |
| POST | `/imports/xlsx` | Import multipart (fichier + `year1`) ; répond 202 avec un job |
| GET | `/imports/{id}` | État et compte rendu d'un import |
| GET | `/rules` | Version et seuils des règles |

Schémas : `Stock`, `AnnualFact` (année, mesure, valeur, devise, source), `Snapshot`, `Qualitative`, `Evaluation` (par horizon : 10 critères avec valeur, seuil strict, seuil assoupli, statut `passed | borderline | failed | missing | insufficient | exempt` ; scores strict et assoupli ; sous-scores ; verdict `excluded | candidate | watch | rejected`), `Job`, `Problem` (RFC 9457). Sécurité : `bearerAuth` (JWT) sur toutes les routes. Chaque réponse a un `example` réaliste (utilisé par Prism).

Génération :
- Serveur Go : oapi-codegen en mode strict → `backend/internal/api/gen/`.
- Client Angular : openapi-generator `typescript-angular` → `web/src/app/api/` (crée `web/` s'il n'existe pas).
- Serveur simulé : Prism (`make mock`, port 4010).
- Lint : Spectral avec `.spectral.yaml` (règles `spectral:oas` + opérations nommées + exemples obligatoires).
