## Objectif

- Sauvegarde nocturne : `pg_dump` → chiffrement age (clé publique seulement sur le serveur) → OVH Object Storage (API S3) ; rétention 30 jours.
- Script de restauration : télécharge la dernière sauvegarde, déchiffre, restaure dans une base neuve, compare le nombre de lignes de chaque table.
- Tâche mensuelle de test de restauration, qui alerte en cas d'échec.
- En CI : MinIO (S3 local) remplace OVH.

## Hors portée

Alertes avancées (phase 5).

## Livrables

- `deploy/backup/` (scripts, conteneur ou minuterie systemd)
- Test d'intégration avec MinIO

## Critères d'acceptation

- [ ] Sauvegarde puis restauration dans une base neuve : nombre de lignes égal pour chaque table
- [ ] La sauvegarde stockée n'est pas lisible sans la clé privée age
- [ ] Les sauvegardes de plus de 30 jours sont supprimées (test avec dates simulées)

## Contraintes

La clé privée age ne quitte jamais ton poste ; le serveur n'a que la clé publique.
