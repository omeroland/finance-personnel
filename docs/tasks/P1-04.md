## Objectif

Créer `backend/internal/modules/stockeval/engine/rules.yaml`, embarqué avec `go:embed`, et un chargeur qui le valide et l'expose en structure typée.

Valeurs exactes à encoder :

| Critère | Strict | Assoupli |
| --- | --- | --- |
| 5a croissance BPA | ≥ 0.08 | ≥ 0.06 |
| 5b hausses BPA (5/10/15/20 ans) | 2 / 4 / 6 / 8 | 1 / 3 / 4 / 6 (D8) |
| 6 croissance dividende | ≥ 0.08 | ≥ 0.06 |
| 7 ratio de distribution | 0 < x ≤ 0.75 | 0 < x ≤ 0.85 |
| 8 dette LT / capitaux propres | 0 ≤ x ≤ 0.70 (D2) | 0 ≤ x ≤ 0.95 |
| 9 variation du dividende | ≥ 0 | (aucun) |
| 10 rachats | baisse sur 1 an (D7) | (aucun) |
| 11a P/E | 0 < x ≤ 25 | 0 < x ≤ 35 |
| 11b rendement actuel vs moyen | strictement supérieur | (aucun) |
| 11c P/B | 0 < x ≤ 3 | 0 < x ≤ 6 |

Paramètres : horizons `[5, 10, 15, 20]` ; moyenne tronquée dès 5 taux ; horizon minimal pour un verdict : 10 ans (D9) ; période de la règle 10 : 1 an, configurable à 5.

Section `compat` : diviseur 18, seuil 5b = 8 sur 20 ans seulement, première transition ignorée dans 5b, bornes basses non vérifiées, donnée vide = réussite, cellule vide = 0, règle 9 `>= 0`.

Le chargeur refuse un fichier où un seuil assoupli est plus strict que le seuil strict, ou où un critère manque. Il expose la version du référentiel (champ `version`) et son empreinte SHA-256.
